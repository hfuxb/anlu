# image_process_stream_96

每拍四个 RGB888 像素，帧首有效拍锁存算法模式和 Sobel 阈值，帧中修改输入模式不改变当前帧。

| 模式 | 输出 |
|---|---|
| RAW / SIG | RGB 通路，识别在独立支路运行 |
| ERO | 灰度 → 标准 Sobel → 3×3 腐蚀 |
| DIL | 灰度 → 标准 Sobel → 3×3 腐蚀 → 3×3 膨胀（开运算） |

全部窗口为当前像素作右下角的因果窗口，越界补零。DIL 窗口只读取已寄存的腐蚀结果，不直接使用 Sobel。细小前景会被腐蚀去掉，后续膨胀无法恢复已消失的点。

## 时序

- 灰度级 → 灰度窗口级 → Sobel 级 → 腐蚀级 → 输出，输出相对采样输入固定延迟四拍。
- RGB、灰度、模式、tvalid、tuser 和 tlast 一起延迟，不受算法模式影响。
- 四像素组边界的左侧两个像素由上一组保存；行尾清除横向历史，帧首行号保护屏蔽未写入的旧帧缓存。
- 两行灰度、两行 Sobel、两行腐蚀缓存不复位，可推断 RAM；无反压，无额外输出或丢弃输入。
- 96→128 位模块保留原提前帧首协议，处理后行尾、有效和像素保持一致。

## 验证

执行 `sim/video720/prepare_opening_golden.py` 和 `sim/video720/run_morphology_sim.ps1`。
参考程序使用标准 Sobel 核和整图形态学计算，不使用 RTL 的打包行缓存实现。测试逐像素比较腐蚀、开运算与 RAW，区分开运算和直接膨胀，覆盖输入空拍、四像素组边界、行尾、帧中模式变化、不复位的连续帧、灰度旁路和 DDR 拼接。
完整 1280×720 用例覆盖四种模式，输出合计 921600 个四像素拍、四个帧首和 2880 个行尾。
