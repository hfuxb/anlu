# 帧差运动检测

MOT（代码 4）在 AWB 后的 RGB 图像上检测相邻帧变化。1280×720 输入每四行取一行，每组四像素用 `(R+2G+B)` 求平均，形成 320×180 的八位亮度参考帧。相同位置与上一完整 MOT 帧亮度差绝对值达到 24，标为运动；同一结果展开到四行、四像素，显示红色覆盖（R=255，G/B 减半）。片上 RAM 保存 57600 字节参考亮度，无额外 DDR 读写。

进入 MOT 的第一帧仅建立参考，不标红；连续静止帧不标红，运动停止后下一帧高亮消失。切出 MOT 或上一帧不完整时丢弃参考有效标记，重新进入需完整一帧后再检测。缓存不复位，使用完整帧有效标记隔离未初始化数据。输入支持有效拍之间的空隙，数据、SOF、EOL、VALID 统一经过两个寄存器级。

这是画面变化提示，不是物体身份识别或距离测量。移动摄像头、自动曝光尚未稳定、光源闪烁或全局明暗变化可能使大片区域标红。建议固定摄像头，等待 AE/AWB 稳定，再移动手或物体进行演示。

DEH 的 11 级与 MOT 的 2 级在所有模式使用一致流水线延迟。非 MOT/DEH 模式的像素原样旁路，ERO 和 DIL 仍使用原来的 Sobel→腐蚀／腐蚀→膨胀结果。像素个数、行帧标记和 DDR 数据布局不变。
