# 当前图像与闭环控制版本改进说明

本说明对应 2026年10月14日上传的当前版本。主工程为 `anlu_lr_tracking_lock_20261012`，本次继续使用 GitHub 分支 `coord-latency-closed-loop-20261013`。

## 本版本已经实现

1. 保持 SC500CS 1280×720 摄像头采集、HDMI输出和自动曝光、自动白平衡。
2. 识别模式 SIG 自动判断环境，在正常RGB识别和去雾RGB识别之间选择。进入去雾需低对比、低色差和暗通道抬高连续满足约0.5秒且至少8帧；回到正常需连续约1秒且至少16帧；自动切换最少保持2秒。
3. KEY3 在 AUTO 和强制正常识别之间切换，防止环境判断导致不合适的去雾。画面显示 `PATH:N AUTO`、`PATH:D AUTO` 或 `PATH:N LOCK`。
4. 去雾显示后加入 Gamma 0.85 与轻度限幅锐化。识别支路使用增强前的RGB，减少对蓝白分类阈值的影响。所有画面保持相同处理延迟和DDR像素布局。
5. KEY4 依次切换 RAW原画、ERO腐蚀、DIL腐蚀后膨胀、MOT帧差运动检测、DEH去雾和SIG识别。只有SIG进行路牌识别与小车视觉控制。
6. 左右转模板使用提供的两张标准标识，保留方向确认、六帧强反向换牌和14帧丢失保持。确认左右转时显示检测框与中心像素坐标。
7. 右上角显示采集到显示的LAT测量，健康数字约每秒更新，减少快速跳变；该测量不包含曝光和显示屏内部处理。
8. 保留STM32编码器轮速PI与物理陀螺仪相对角度闭环。FPGA请求相对±90°动作，STM32执行并返回动作状态、故障和完成反馈。

## 构建和验证

- 普通bit：`fpga/traffic_sign_td/td_project/bitstream/traffic_sign_td_lr_tracking_lock.bit`。
- 同设计压缩bit：同目录的 `_compress.bit`。
- 四驱STM32固件：`stm32/WHEELTEC_C50X_FPGA_PD89/OBJ/cli_4WD/4WD_Car_FPGA_PD89.hex`。
- 最终Slice占用88.36%，ERAM占用64.81%，DSP使用38/40。
- 最终布线Setup WNS为+0.121ns，Hold WNS为+0.020ns，两项TNS为0；环境选择、Gamma/锐化、完整720P流与原控制链路的仿真记录见构建结果。
- 软件仿真与编译通过不代表实车转向、真实雾场景或制动距离已经验证。用户已反馈雾图可以触发；仍需实际场地联调。

## 超声波升级的边界

本次首先保存并上传上面的当前版本。本包没有超声波测距、根据障碍距离选择转向时机或无路牌绕障功能；这些功能在独立的新工程 `anlu_ultrasonic_navigation_20261014` 中开发，避免把旧bit或旧HEX误当成新增功能固件。
