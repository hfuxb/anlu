# 自动正常／去雾识别与显示增强

本次在 `anlu_lr_tracking_lock_20261012` 原位修改。保持 1280×720、AE/AWB、14帧丢失保持、六帧强反向换牌、坐标、慢速 LAT 显示、原 STM32 角度执行与反馈协议。

## 操作

- KEY4 短按释放：RAW → ERO → DIL → MOT → DEH → SIG → RAW。
- SIG 自动选择正常 RGB 或去雾 RGB 送入同一个识别器，不增加一个独立识别器，不重置已锁定方向。原方向确认／换牌／丢失规则仍然有效。
- SIG 中 `PATH:N AUTO` 表示当前正常识别；`PATH:D AUTO` 表示当前去雾识别。
- KEY3（原 `I_car_obstacle_n`，B9）每次按下去抖后切换 AUTO／强制正常识别。强制模式显示 `PATH:N LOCK`，下一完整帧起生效；再次按下恢复 AUTO，重新累计环境证据。
- 手动选择在 KEY4 切换画面后保持，复位恢复 AUTO。KEY3 不关闭独立 DEH 展示画面的去雾。
- KEY3 已从原障碍模拟按钮改作识别选择；KEY2 仍停车。真实避障输入尚未增加，不能把本次模式按钮当作避障传感器。

## 自动条件

所有环境统计取自 **AWB 输出、去雾之前**。每64个横向像素、每8行取一个像素，共1800个采样点／完整720P帧。

用16档亮度直方图，排除两端各约1/32采样点，得到约P3/P97的亮度跨度；对少量灯管／高光更稳健。均值通过累加与常数移位比较，不使用视频流中的除法器。

进入去雾识别需要同时满足：

1. 裁剪后的亮度跨度不超过5档（约80个灰度级）。
2. 平均 RGB 最小通道值 ≥48。
3. 平均 RGB 最大值与最小值之差 ≤40。
4. 连续符合约0.5秒，而且至少8个完整帧。

回到正常识别需要：亮度跨度≥8档（约128），或平均最小通道<32，或平均通道跨度>56；连续符合约1秒，至少16个完整帧。每次自动切换后最少保持2秒。时间按照60MHz CSI时钟和实际完整帧的SOF间隔计算，未假定固定30／60帧率。自动决定只在 SIG 中推进；专门的 DEH 展示不参与识别。

切换在有效帧首锁存，帧内不改变路径。残缺帧清除连续证据，超过0.25秒的帧首间隔也清除累计证据。当前自动路径选择会保留至下次 SIG 环境判断；KEY3强制正常有最高优先级。

这些是低对比、低饱和、暗通道抬高的**雾化启发式判断**，不是物理雾浓度测量。灰白且平坦的无雾场景也可能满足条件；进入去雾后效果不佳时使用 KEY3。阈值仍需实际摄像头与赛道测试调整。不使用已锁定／保留的 MATCH 来判断环境。

## 流水线

AWB → 共用去雾／等延迟直通 → 分支：

- 识别支路：正常或去雾 RGB → 原蓝色候选／箭头模板／方向锁定。
- 显示支路：原空间算法 → Gamma／等延迟直通 → 轻度限幅锐化 → MOT／等延迟直通 → DDR → HDMI。

去雾模式 DEH 和 SIG 的自动去雾路径均显示增强画面。其他模式逐像素直通增强模块。Gamma、锐化不进入识别支路，避免改变蓝白阈值；显示的识别框仍对应同一图像坐标。

Gamma采用256项查表，Y=(R+2G+B)/4、指数0.85。计算Gamma(Y)-Y并给三个通道加入相同偏移，最终饱和到0～255。锐化采用因果2×2亮度邻域（当前、左、上、左上），细节差值±4以内不增强，超过部分按1/4强度增强，最终偏移限定在±4；首行／首列复制边界。它是资源受限的轻度锐化，不是完整对称3×3滤波或重建失焦细节。

共用去雾11级、增强7级、运动2级，共20级额外处理延迟；比原额外13级多7拍。所有模式等延迟、有效空拍也保持同步；不增加／删除像素，不改变 DDR 布局、HDMI 有效分辨率或读取时序。只有一套去雾核心，避免重复使用 DSP。

## 验证边界

`sim/auto_dehaze/run_upgrade_sim.ps1` 验证环境迟滞、KEY3、Gamma和锐化独立逐像素参考、真实左右模板在合成雾中的路径切换，以及 PATH 字符像素。`sim/extra_modes/run_extra_sim.ps1 -Only tb_isp_modes` 验证实际ISP与96→128位DDR打包。

原左右方向及14帧保持逻辑未改。合成雾识别结果不等于实物准确率；最终资源、时序与 bit 校验值记录在构建结果中。尚未下载至实物开发板，也未验证实际雾、灯光和小车行为。
