# 检测框中心坐标仿真

工程原位修改，检测器与小车控制协议不变。SIG 页面存在有效检测框且结果为 `L` 或 `R` 时，框上方显示 `L (0640,0360)` 或 `R (0640,0360)`。坐标是 1280×720 图像中的框中心像素，整数向下取整，并以四位十进制显示。候选 `?`、等待、无框与非 SIG 页面不显示坐标。原来的 14 帧目标保持仍由检测器负责，显示端不改变保持策略。

13 个字符统一使用 16×16 字库。标签为 208×20 像素，背景与已识别框同为绿色，文字为深色。靠上时放入框内；靠右时水平限幅；必要时移动标签以避开左上 Logo、固定状态和右上 LAT。检测框与报告的实际坐标不会因文字避让而改变。

框、方向与坐标输入在同一个 HDMI 帧首锁存。中心值转换为 BCD 使用 12 个时钟的顺序 double-dabble，显示像素路径不使用除法或大乘法。

在工程根目录运行：

```powershell
& '.\sim\coordinate\run_coordinate_sim.ps1'
```

- `tb_coordinate_hdmi`：14 个完整 1280×720 帧；逐像素检查坐标字符、背景、十进制与前导零、候选/无框隐藏、低分保持、新中心、边界位置和模式退出/重入，并校验 RGB、DE、同步与 DDR 读使能保持原流水延迟。既有固定状态字符和分数条的覆盖优先级由 `tb_lr_hdmi` 单独验证。
- `tb_coordinate_latch`：启用 LAT 的 14 项检查，包含 LAT/Logo/状态避让、帧内元数据保持、中心 BCD 和进入 SIG 时的旧结果清除。

通过日志写入 `reports/tb_coordinate_hdmi.log` 与 `reports/tb_coordinate_latch.log`。仿真不代表实物识别率或实际距离测量。
