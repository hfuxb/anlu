## 操作与显示

1. 加载新 bit，等待摄像头 AE/AWB 稳定。默认 RAW 模式不识别；短按并释放 KEY4 五次，经过 ERO、DIL、MOT、DEH 后进入 SIG，才运行识别。
2. SIG 中正对完整蓝底白箭头圆牌，建议圆牌直径 100～300 个相机像素，保持片刻。进入 SIG 会初始化统计 RAM 并等待新的完整帧，起初可能显示 DIR:WAIT；不会恢复退出前的旧框和方向。
3. 首先显示黄色候选框、`DIR:?`。同一位置关联目标的匹配分数 ≥50、左右分数差 ≥12，并且连续三帧方向相同，才显示绿色框及 `DIR:L` / `DIR:R`。
4. 锁定后，框按目标位置与大小更新。MATCH 偏低或短暂误判时，保持当前 L/R。相反方向连续 **六帧**满足 MATCH ≥65、左右分数差 ≥20 且目标位置关联有效，才更新为新方向。
   弱匹配、当前方向或目标丢失会清零换牌计数；换牌确认期间继续显示旧方向，确认时 ASCII、class 和框结果在同一发布周期更新。
5. MATCH 仍显示当前匹配分数，属于前景交并比，不是识别概率。绿色框表示已锁定，不能只看 MATCH 判断是否锁定。
   确认 L/R 且框有效时，框上方显示 `L (0640,0360)` 或 `R (...)`，数字为框中心的图像像素坐标，左上原点，范围 X=0～1279 / Y=0～719。未识别、候选 `?`、WAIT、无框或非SIG不显示坐标。文字沿用16×16字格，横向裁切保护并避让Logo、固定状态及LAT；框靠近顶部时标签放框内。保持阶段坐标对应当前保留的目标框，不是新的测距结果。
6. 目标短暂被遮挡或消失，前十三帧保留上次框及方向；连续丢失第十四帧清除框和方向，恢复 `?`，重新开始搜索。当前摄像头配置下十四帧约 0.235 秒。重新找到关联目标时，丢失计数清零。
7. 可以直接在同一位置将左牌换成右牌，或右牌换成左牌。保持新牌完整、清晰、大小相近，等待六帧合格结果即可更新，不需要先移走到框消失。若新牌得分不足 65，旧方向继续保留；移走目标连续十四帧后可重新按初次门槛确认。
8. KEY4 短按并释放切换 `RAW → ERO → DIL → MOT → DEH → SIG → RAW`，识别位于最后。只有 SIG 运行识别并显示 DIR、MATCH 和框。其他模式保留模式、Logo、计数、延迟，隐藏全部识别叠加。KEY4 长按仍按小车慢速逻辑处理。
9. 切出 SIG 立即取消识别并清除旧锁定，不等待十四帧；重入后重新确认。接小车时非 SIG 通过现有停车入口发送零速度并撤销 armed，回到 SIG 不自动启动，需重新按 KEY1 ARM。
10. `ERO` 是 Sobel 边缘图的 3×3 腐蚀；`DIL` 是该腐蚀结果的 3×3 膨胀，即开运算。DIL 已不再直接膨胀原始边缘，孤立点和太细的边缘可能被去掉。
11. `MOT` 为帧差运动检测：相邻完整帧的 320×180 亮度网格差值达到 24，展开成 4×4 红色变化区域。进入后的第一帧先建立参考；静止物体随后不再标红。演示时固定摄像头，等待 AE/AWB 稳定，再移动手或物体；移动摄像头、闪烁和整体亮度变化也会触发。
12. `DEH` 为轻量暗通道去雾：固定大气光 240、权重约 0.85，以六档移位增益恢复 RGB。适合观察低对比的雾化画面，无雾画面也可能变暗或饱和；这不是自适应雾浓度估计。
13. 所有画面右上角显示 `LAT:xxxx.xMS`，例如 `LAT:0033.6MS` 表示 33.6 毫秒。每帧仍在共同的0.1毫秒时间基准下测量MIPI/CSI帧首到该DDR帧首个HDMI有效像素的时间；为方便阅读，健康数值约每1秒在帧首更新为最近一次完整测量，期间保持显示，不做平均。首次有效值、无效/溢出及恢复立即发布；1.5秒没有测量更新显示无效。重复显示旧帧时每帧测量会反映其实际年龄，OSD显示的是最近发布值。它不包含摄像头曝光和屏幕内部缩放/扫描延迟，也不等于单纯的算法执行耗时。未取得完整有效帧标签显示 `LAT:----.-MS`；超过9999.9毫秒显示 `LAT:OVFL  MS`。

## 算法和指令链路

- `traffic_sign_sig_only_96` 包装原检测器：独立单比特 SIG 请求跨时钟，初始化完成后在帧首放行，退出时中止半帧并发一次清空结果事件；RAW/ERO/DIL/MOT/DEH 不把像素送给核心，结果 toggle 不随模式归零。模式总线已扩为三位，SIG 的完整比较为 0，避免 MOT 的低两位 00 误启识别。
- 首次搜索使用蓝色游程候选，左右 16×16 模板分别从用户于 2026-10-12 提供的两张正式标识提取。两份模板使用与 RTL 一致的蓝/白阈值、4×4 采样、归一化和内部掩膜。
- 每帧选择与上次位置最接近的合格候选：宽高变化各不超过约 25%，中心移动不超过对应跨度的 1/4 加 16 像素。
- 未锁定时，如果没有关联候选，重新选择合格蓝色面积最大的目标，重置方向确认；不使用原目标得分给新目标赋方向。
- 锁定期间只允许关联候选更新位置；远处更大的蓝色区域不能抢占目标。
- 保持期间，检测器的 ASCII 方向、class、result_valid、HDMI 元数据均同步保持；换牌确认时同步更新。SIG 中再按三次稳定结果发一次带序号的 STM32 相对角度请求；同一请求周期重复保活，不能重启动作。执行中不会因单帧方向或分数变化改变目标角度。
- STM32 根据经过身份、量程、ACK、校准和新样本检查的陀螺仪 Z 角速度积分相对角度，外环输出角速度，原轮速 PI 执行电机目标。FPGA 只有先收到匹配 ACCEPTED/RUNNING，再收到匹配 DONE 才结束转向；状态/编号异常或超时停车并撤销 ARM。退出 SIG 同样立即停车，重入仍需人工 ARM。
- 识别换牌逻辑在帧结束后执行。开运算增加一组腐蚀行缓存和一个寄存器级，RGB、灰度、模式和有效/帧首/行尾统一从三拍延迟改为四拍，数据个数与 DDR 访问量不变。
- 修正 Sobel 水平梯度的中行右侧像素：`gx` 使用 `m_c` 而不是 `m_l1`。
- 新增 `image_extra_modes_96`，共用 DEH（11级）位于空间算法及识别器之前，显示支路增加 Gamma/限幅锐化（7级）和 MOT（2级）。所有模式统一增加 20 个时钟的额外流延迟，ERO/DIL 的像素值不变，视频布局及访问量不变。
- 延迟测量使用四个帧标签、Gray 时间同步和请求/应答元数据跨时钟；完整帧所有 RGB 字进入有序 DDR 命令 FIFO 后才标记有效。不完整帧、错误帧或缺少当前显示帧标签均不会沿用旧测量。

## 当前边界

- 转向时机仍为三次稳定识别确认，未增加路口位置、牌距或行驶距离判断。MOT 不是避障传感器。本版完成的是角度执行和反馈闭环，实车仍需验证 IMU 正负方向、校准和转向精度。
- 两张正式标识的独立模板继续使用。初次匹配门槛为 50/差值12/三帧，换方向门槛为 65/差值20/六帧；MATCH 是模板交并比，不能视为实物准确率。
- 圆牌大小仍需约 64～512 相机像素，最多八个蓝色候选，只跟踪一个目标。
- 快速大幅移动、蓝色物体相连、被同位置相似蓝色物体替换，可能导致丢失或错误关联。位置和颜色跟踪无法独立验证同一物体的身份。
- 强相反证据连续六帧才允许改向，单帧误判不改向；持续错误的高分匹配仍可能改向。新的牌长期低于换牌门槛时，仍需改善拍摄条件或移走重新确认。
- 保留时长以摄像头帧数计算，不是永久框住空背景。MOT 是独立画面变化检测，不用于识别锁定或小车避障；SIG 自动去雾时 DEH 核心输出送入同一识别器；单独 DEH 展示仍不运行识别。
- 所有 Latin 字母、数字、冒号及问号统一 16×16 字格，采用同一 10×14 笔画尺度；标题计数数字取消独立拉伸。汉字保留原绘制尺寸。
- Logo 地址提前一拍计算和寄存，匹配坐标 1d→2d；RGB、同步信号和视频读取延迟不变。
- 参考标识原图、蓝色区域裁切、实际网格模板和 SHA-256 在 `sim/lr_turn/reference_20261012/`，复现脚本为 `prepare_reference_signs.py`。
- RTL 仿真不能代表实际摄像头准确率，上板后仍需验证距离、照明、运动和纸质/屏幕展示条件。

当前自动路径是雾化启发式选择，不是雾浓度传感器；灰白平坦的场景可能误触发。KEY3可强制正常识别，KEY2仍停车。KEY3已不再作为障碍模拟按钮。新功能尚待实际摄像头／雾环境测试。
