# `design_top_wrapper` 模块规格

## 链路错误路径

- CSI 时钟域锁存 `S_lane_error`，在 RAW10 帧结束时发送帧状态 toggle。
- 如果上一帧没有结束标记但检测到下一帧开始，上一帧按链路错误发送。
- DDR 时钟域对 toggle 和状态分别进行两级同步，并把已捕获状态送入 `video_in`。

## DDR 请求仲裁

- `video_in` 和 `video_out` 输出突发请求，由顶层按突发级仲裁。
- 同一 DDR 时钟拍最多允许写或读一个方向获得 ready，禁止写读同时进入共享命令 FIFO。
- `S_ddr_turn` 只在突发结束后改变，用于两个方向同时请求时的公平选择。

## 验证边界

- ModelSim 需要覆盖链路错误、丢帧结束标记、写突发和读突发同时请求。
- TD 需要确认新增同步寄存器、仲裁逻辑和 eRAM 使能不会引入综合或时序错误。
