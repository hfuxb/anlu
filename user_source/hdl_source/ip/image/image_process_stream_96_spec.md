# `image_process_stream_96` 模块规格

## 数据通路

- 输入为每拍四个 RGB888 像素。
- Stage 0 计算 `77*R`、`150*G` 和 `29*B`，但使用移位加法实现。
- Stage 1 完成三项求和并取高 8 位。
- 后续行缓存、Sobel、形态学处理和输出标记保持原有流水级。

## 时序约束

- 不增加或删除寄存器级。
- `I_tuser`、`I_tlast`、`I_tvalid` 与像素数据沿原有控制流水线传递。
- 移位加法保留 17 位中间结果；当前 8 位输入下与原常数乘法结果一致。

## 验证边界

- 需要使用 `sim/tb_image_process_stream_96.sv` 和完整帧测试检查灰度、标记和输出流水延迟。
- ModelSim 仿真和 TD 结果必须使用本次修改后的运行记录；历史报告不作为本次通过证据。
