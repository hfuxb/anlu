# `cnn_weight_rom` 模块规格

## 存储组织

- 17 个 64 位物理 bank，每个逻辑字包含 8 个有符号 INT8 权重。
- `addr[14:10]` 选择 bank，`addr[9:0]` 选择 bank 内逻辑字。
- bank16 的逻辑字 937 至 1009 保存 146 个 32 位偏置值。

## 访问约束

- 每次只使能当前权重 bank；读取偏置时只使能 bank16。
- `ena` 只改变非选中 bank 的活动和仿真输出，不改变权重地址映射、数据打包或 `cnn_core` 接口。
- 权重初始化文件仍为现有 17 个 `.bin` 文件。

## 验证边界

- 必须检查 bank 边界、bank16 权重/偏置边界和禁用 bank 的输出。
- TD 结果用于确认 `PH1P_LOGIC_ERAM` 参数和资源映射；仿真用于确认数值和地址映射。
