# `cnn_core` 模块规格

## 作用

`cnn_core` 对采样器提供的 64x64 灰度图执行当前迁移网络的卷积和全连接推理。模块使用一个八路并行 MAC，并通过现有握手接口向采样器返回分类结果。

## 接口约束

- 输入数据：`input_rd_data[7:0]`，无符号灰度值。
- 输入存储器接口：`input_rd_bank`、`input_rd_addr[11:0]`、`input_frame_ready`。
- 控制接口：`start`、`busy`、`done`。
- 结果接口：`result_valid`、`result_class[4:0]`、`result_ascii[7:0]`。
- 不增加顶层物理端口。CNN状态由 `isp_top` 和结果CDC模块在工程内部连接。

## 数据通路

1. Conv1：3x3 灰度卷积，八个输出通道并行计算。
2. Conv2/Conv3：八通道输入组复用同一 MAC，结果写入特征图 RAM。
3. FC1/FC2：按 64 位特征字读取，执行分类层累加。
4. 最后一级输出 26 类结果，`result_ascii` 使用 `A` 到 `Z` 编码。

## 位宽规则

- 单项乘积：有符号 16 位，范围为 `-32640..32385`。
- 八项 MAC 和：有符号 19 位，范围为 `-261120..259080`。
- 卷积累加器：有符号 23 位，覆盖当前 Conv1/Conv2/Conv3 的最大累加范围。
- 全连接累加器：当前网络使用有符号 26 位；偏置先寄存，再进入每个输出神经元的累加器。该宽度覆盖当前量化范围，并为后续功能扩展保留逻辑资源。
- 每一级加法均显式符号扩展，禁止依赖 Verilog 隐式扩展规则。
